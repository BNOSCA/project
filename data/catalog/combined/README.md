# App-ready combined catalog

`products.json` contains 1,012 products: 500 local Kaggle image records and 512 official GU/UNIQLO records. It is generated by `python3 scripts/build_combined_catalog.py`.

- Kaggle images use `/products/kaggle/<id>.jpg`; FastAPI serves them from the `images` link in this directory.
- Kaggle records have no verified price or product page, so `price` and `product_url` are `null`. They appear in search but are excluded from budgeted outfit generation.
- Official records retain the official HTTPS product page and CDN image URLs, and can participate in search and outfit generation.
- `posts.json` contains the 20 editorial fixture posts and `creators.json` contains their four creators. Each post links to one official catalog item marked `similar`; these links are metadata matches for the demo and do not claim the creator wore that product.
- The builder reclassifies two shoe-shaped charms from the official snapshot as accessories so they cannot appear as footwear in a complete outfit.

Run the backend with this catalog:

```bash
APP_DATA_DIR=./data/catalog/combined .venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```
