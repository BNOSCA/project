# 官方品牌商品 catalog

此目錄保存從 GU Taiwan 與 UNIQLO Taiwan 官方商品頁核對的精選商品。圖片保留為官方 CDN HTTPS 連結，前端可直接透過 `image_url` 存取；`image_urls` 是商品頁可見的圖片集。

`source_checked_at` 是擷取日期。價格、庫存、尺碼和頁面內容會變動，正式展示時要在前端標示來源與核對日期。`attributes` 保存品牌頁的可比對附加欄位；未能從來源取得的資料不填寫，也不以推測補值。

資料目前有 512 筆：原有 12 筆商品頁詳情資料，及 500 筆由 GU Taiwan 官方 WOMEN／MEN 商品清單擷取的商品快照。清單快照含名稱、售價、性別、尺寸摘要、商品頁、官方圖片路徑與頁面可見標示；未逐筆開啟商品頁取得的材質、洗滌方式等欄位維持空值。
